WinoGrande Phase 5 Brief

Follow-up to the team meeting on the WinoGrande STR brief. The main point raised there was that our WinoGrande setup asks the question backwards. So we asked it the original way, added the controls that were suggested, and reran the full analysis on every condition: layer patching, add-back curves, heads plus experts, and knockout.

Answers at a glance

Is the option swap the same as the original task?No. Asking for the entity instead of the adjective flips the picture. On the same twins, attention's share of the repair goes from 0.19 to 0.71 (Qwen3) and from 0.35 to 0.52 (Mixtral). In this direction attention writes the answer, as in IOI.
Is it about the answer being in context?Hardly. Listing both adjectives in the prompt, so the answer can be copied, moves attention's share by only +0.07 / +0.04.
Association, verbs, memorisation?Small effects:
  • Association balance changes the share by at most 0.11.
  • A neutral verb changes nothing measurable.
  • An unrelated verb removes the effect, so the models read the verb.
  • The original names do no better than new names, so there is no sign of memorisation.
Is there a gradient of attention across tasks?Two blocks rather than a smooth gradient. Every "which attribute" task is MoE-heavy and every "which entity" task is attention-heavy. CounterFact sits between them and IOI above both.
Why do the add-back curves look different?Experts in the last four layers push against the answer. When attention writes the answer, an experts-only add-back overshoots the all-MoE line. When the experts write it, the curve just rises to the line. We tested this directly.
Attribution patching instead of activation patching?On OLMoE it matches exact patching for experts (r 0.96–0.97) but underestimates early heads. For final-position work, exact patching is cheap enough.

1 · Setup: the same twins, asked two ways

A WinoGrande twin pair differs in one trigger word, and that flips the answer. Phase 3/4 filled the blank and asked for the trigger: entity → attribute. The original task gives the trigger and asks which entity the blank refers to: attribute → entity. In both, the corrupted prompt is the twin, and we patch at the last token.

Phase 3/4, entity → attribute (swap the filled noun, read the adjective) A: The janitor tried to clean the mirror with the spray but the mirror was too → " dirty" B: The janitor tried to clean the mirror with the spray but the spray was too → " weak" Phase 5, attribute → entity (swap the trigger, read the noun) A: Fill in the blank: The janitor tried to clean the mirror with the spray but the _ was too dirty. Answer: the → " mirror" B: Fill in the blank: The janitor tried to clean the mirror with the spray but the _ was too weak. Answer: the → " spray"
  • Same information as WinoGrande. Every prompt contains the whole sentence; only the answer is withheld.
  • Filters:
    • single-token answers;
    • twins of equal token length that differ in at most 3 tokens;
    • the model gets both twins right by at least 1 logit.
  • Association balance.
    • A probe shows the model each trigger word and the two candidates, without the sentence. Example: Word: dirty. Which fits better, the mirror or the spray?, plus a second probe in the fill-in-the-blank format.
    • The main sets keep only pairs where neither trigger points to an answer on its own: |probe| < 1 logit for both.

Takeaway.
  • Same sentences, different question, different mechanism. The experts alone undo 0.81 / 0.75 of the damage when we ask for the adjective, but only 0.10 / 0.41 when we ask for the entity. In that direction attention writes the answer directly (1.08 / 0.86), as in IOI.
  • The instruction wrapper is not the cause. The natural-sentence version without "Fill in the blank" gives the same picture: attention share 0.69 / 0.65.

  • Unrelated verb ("talked with" instead of "gave a hand"): the effect disappears. The mean drop falls from about 5 logits to 0.2 / 0.0, so the models use the verb.
  • Memorisation. The templates with their original WinoGrande names pass the competence filter no more often than with new names (0.31 vs 0.38 Qwen3, 0.31 vs 0.29 Mixtral).
  • Copy prefix design. Our first prefix, "Of Sarah and Laura, one was helpful and the other was overwhelmed", let the model match names to adjectives by position. Mixtral passed 43 % of items in one order and 0 % in the other, even with an unrelated verb. We replaced it with a neutral list before running any patching.
Takeaway. The direction of the question matters far more than whether the answer is in context, how strong the noun–adjective association is, or which verb is used.

4 · The task ladder

Every task on one axis, both models, validation pairs with 95 % CIs. Tasks are ordered by attention's share of the repair. The other panels show the direct attention share, the all-MoE add-back, and how many of the first 10 picks are attention heads when heads and experts are added back together.

Takeaway.
  • Two blocks, not a gradient.
    • "Which attribute" tasks, with or without a copyable answer: 0.16–0.31 (Qwen3), 0.34–0.42 (Mixtral).
    • CounterFact: 0.54 / 0.58.
    • "Which entity" tasks: 0.69–0.79 / 0.52–0.65.
    • IOI: 0.92 / 0.80.
    The two models order the tasks alike (Spearman 0.90).
  • The attention-heavy subset we were asked to find is attribute → entity on name items. There, 9 of the first 10 picks are heads (Qwen3).

Caveat: "which entity" vs "which attribute" also changes the answer type (a word from the context vs a new word) and the prompt length (27–32 vs 17–19 tokens). The instruction wrapper is ruled out by the natural-sentence condition.

  • The WinoGrande expert is needed only for entity → attribute on object items, even when the answer is copyable. For name items Mixtral uses L19E006 instead (0.017–0.042).
  • Qwen3 has its own attribute → entity expert, L37E032. It is selected in the fill-in-the-blank pool and again on the name templates, and knocking it out costs 0.042 of the margin. Yet it writes almost nothing to the answer directly (direct share 0.01). It computes something that heads L40H2 and L42H10 then use to move the entity to the answer. This fits the "find, think, then bring the answer" picture from the meeting.
  • Each condition's own top-10 experts cost 0.02–0.29 of the margin when knocked out together; matched random sets cost ≤ 0.04.

6 · Why the add-back curves look different

greedy
At each step, add the expert that helps most given the ones already added (15 steps).
oracle
Add each case's experts in order of how much each helps on its own.
random
Random order, average of 5.
dashed line
Every MoE output put back at once.

Each point is one condition and model. The y-axis is how far the best expert subset rises above the all-MoE line. Left panel: the x-axis is how much more we restore when the last four layers are left out (r = 0.98).

What happens.
  • The late experts push back. Every task has experts in the last four layers that write against the answer. They push harder the more evidence for the answer is already in the residual stream.
  • An experts-only add-back restores only half of that evidence. It brings back what the experts wrote, but not what attention wrote.
  • When attention writes the answer (the entity question, CounterFact), the all-MoE line includes the late experts' push-back against evidence that is missing from the patched run. Leaving those experts out therefore beats the line.
  • When the experts write the answer (the attribute question), nothing is missing, so there is nothing to gain.

7 · Attribution patching (pilot on OLMoE)

ComponentGradient estimate vs exact patching (r)Noise ceiling
Single experts0.96 · 0.970.97 · 0.96
MoE layers0.96 · 0.991.00 · 0.99
Attention heads0.83 · 0.950.92 · 0.94

WinoGrande · IOI, 64 + 64 pairs each. The noise ceiling compares two exact-patching implementations.

  • Experts and MoE layers: the gradient estimate is as good as the measurement noise allows. Used as an add-back ordering, it equals the oracle.
  • Early heads are underestimated. The strongest WinoGrande head ranks only 6th.
  • Routing changes. About a third of single-expert patches change which experts later layers pick, which a gradient cannot see.
  • Our call: no need to build a gradient engine for the 30B models. Exact patching at the last token costs about 5 GPU minutes per 256 prompts. It would pay off only for all-position or edge-level attribution.

8 · Not done, and caveats

  • Not run: the A/B letter format, synonym averaging, a model-size series, and anything for MIB. These remain for discussion. The same-family Qwen3-235B does not fit on our disk; the dense Qwen3 family (0.6B–32B) is a possible scale series.
  • Base models rarely solve some formats. They mostly fail the entity question on the name templates (3.7 % / 0.1 % pass) and a restated format ("The one who … was", 9 %). Those are reported as behaviour only.
  • Small samples: the natural-sentence condition (32 / 18 pairs) and the entity question on templates (5 validation templates). Template results use template-clustered CIs. Mixtral has few name items in the entity direction.
  • The curve-shape test was run on Qwen3 only. The cross-condition correlations rest on about 20 points.
